## API で変えた点

- 旧 `App::execute_palette_command` / `App::command_enabled` → `command::execute(&mut Workspace, id)` /
  `command::enabled(&Workspace, id)`。使えない理由は `Enabled::No(&str)` が持ち、
  メニューはそれで灰色にし、パレットは実行時に Status へ出す (旧はパレット側に理由が無かった)
- 旧 `MenuState` (`bar_hits` / `item_hits` / `dropdown_area` を描画が書き戻す) → 状態は
  `MenuBar` の 3 バリアントだけ。座標は `title_spans` / `dropdown_rect` / `item_at` の
  純関数が `Layout` から引き直す
- 旧 `MenuFocus::Open` の `scroll` フィールドを廃止。窓は `scroll_for(selected, len, height)`
  が選択から導く
- `Effect::Command(CommandId)` を追加し、メニュー・パレット・keymap の 3 経路を 1 本にした

## 旧との挙動差

- 自己更新の 2 コマンド (`CheckForUpdate` / `UpdateAndRestart`) はメニューの位置も
  パレットの表も旧のままで、中身だけが後続フェーズ待ちのスタブ。更新情報を持たないので
  `enabled` は今は常に灰色にする
- タイトルバーはリポジトリ名を `theme.accent` のバッジで出す。旧の名前から色を導く
  `name_to_color` と右寄せの更新バッジは後続フェーズ。ccusage のトークン数と費用は
  計画書 3 章で落とした
- ステータスバーの最初の 500ms の背景明滅は入れていない。明滅させると `liveness` が
  Active を返し続ける必要があり、tick を上げる理由を装飾に持たせたくない。
  2.5 秒でのフェードと 3 秒での消滅は旧のまま
