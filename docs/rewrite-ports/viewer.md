## API で変えた点

- `ViewerState` → `ViewerPanel`。状態は tabs / content / diff / search / fold / selection / scroll の
  7 つで、アクティブなタブのぶんだけが実体を持つ不変条件は旧のまま
- ファイルの読み込みと折りたたみ範囲の算出は svc のワーカーへ (`Task::LoadFile`)。結果は通し番号で
  照合するので、続けて開いても古い結果が新しい本文を上書きしない
- `FoldState::rebuild(source, path)` → `fold::compute(source, path) -> Vec<FoldRange>` (ワーカー) +
  `FoldState::install(ranges, path)` (UI)。開閉を引き継ぐ判断は UI 側に残した
- `UnifiedDiffEntry` → `diff::Entry`。`old_line_no` を持たせた (左右 2 列の左側が読む)
- `gutter_total_width` は消えた。ガター幅は描画が行数から求め、マウスの当たり判定は
  フェーズ 3b でその同じ関数を呼ぶ
- ファイル内検索は `Modal::Prompt` で受ける。旧はパネル内の入力欄で 1 打鍵ごとに検索していたので、
  **確定してから検索する挙動差がある**
- 行のクリックは `ViewerPanel::click` が受ける (ガターとテキストを分けない)。ホイールは
  `scroll_lines`。旧はガターの `+` バッジだけがクリック対象だった
- `media.rs` の ASCII アート描画は持ち込まない。開けないファイル (メディア、バイナリ、5MiB 超) は
  理由を 1 行出す
- 左右 2 列は新規実装。旧は `[diff] default_view = "side-by-side"` が設定にあるだけで、描画は
  分岐していなかった (`DiffViewMode` を読む箇所が無い)。`Action::ToggleDiffView` を
  conductor-core の語彙に足し、`[layers.viewer_diff_mode]` の `s` に割り当てた

## 残したコメント (なぜ)

- `fold.rs` モジュール doc: 可視行を数える場所が 2 つできると描画・ヒット判定・検索の着地点がずれる
- `fold.rs` `foldable_kinds`: 「複数行のノード全部」にしない理由 (マーカーが増えすぎる)
- `fold.rs` `normalize`: 同じ行に 2 つあると開閉が 1 エントリを取り合う
- `fold.rs` `reveal` / `visible_anchor`: 隠れた行に着地したときの振る舞いの根拠
- `syntax.rs` モジュール doc: two-face を使う理由 (着色スコープ数の実測)
- `syntax.rs` `embedded_theme_for`: 同名の組み込みが無いテーマの代用の選び方
- `syntax.rs` `syntect_theme_for`: 参照するテーマ名を `theme_name()` に一本化する理由
- `syntax.rs` `find_syntax`: ファイル名を拡張子より先に見る理由
- `content.rs` `Content::error`: 「未選択」「空」「読めなかった」を見分けるため
- `content.rs` `read`: 折りたたみを展開前のテキストから求める理由
- `mod.rs` モジュール doc: 実体を 1 つに保つ理由、相対パスの解決先がここである理由
- `tabs.rs` `drop_preview`: 添字を詰めないと隣のファイルが開く
- `diff.rs` `DiffPane::max_line_no`: Line だけからは求まらない

| 読めない画像は理由になる / 画像は升目に収まる行になる | 同上 | aa-media を実際に通し、行が升目を超えない |
| ファイルサイズは単位付きで出す | 同上 | 情報行の文言 |
| 画像は区画の大きさごとに一度だけ描く | `viewer/mod.rs` | 鍵は (パス, 桁, 行)。同じ大きさなら Task を投げ直さない |
| 実行できるテストは読み込みと同時に見つかる | `viewer/content.rs` | 走査は読み込みのワーカーの中。開いた後に別に走らせない |
| 実行ボタンを押すとテストのコマンドがシェルへ行く | `viewer/mod.rs` | 押した行のテストだけ。Viewer は PTY を知らない |
| テストのコマンドはシェルが無くても起こして流れる | `panels/terminal/mod.rs` | 本物の `/bin/sh` を起こして出力を待つ |

## 旧との挙動差 (フェーズ 5a)

- 動画 (mp4 / mov / webm / avi) はプレビューしない。旧は「メディア」として同じ経路に
  流していたが、描画は `image::open` なので必ず「Failed to load image」になっていた。
  新は素のテキストとして開けない拡張子として扱い、その旨を出す
- 画像は失敗しても `content.error` にしない。読めなかった絵と「開けないファイル」は
  別の表示で、後者はタブごと開かない
