## 新設 (旧に対応が無い不変条件)

| 新テスト名 | 何を固定するか |
|---|---|
| 別のセッションの結果は捨てる (`panels/terminal/mod.rs`) | 読む先は pin した session id だけ。/clear のローテーション中に届いた古い結果を載せない。照合は `install_transcript` の 1 箇所 |
| 追従中に行が届いても末尾に居続ける | 行が伸びたときに follow が末尾へ再固定する |

## API で変えた点

- 行の組み直しは `render` ではなく `Reflow::prepare` で行う。render は `&Reflow` しか取らない
- `MarkdownCache` は無くなった。組み直しは幅の変化と展開トグルのときだけなので、
  毎フレームの再描画を避けるためのキャッシュは要らない
- 「最新へ」チップの矩形は描画の副産物ではなく `render::badge` の純関数。
  描画とマウスの当たり判定が同じ答えを見る
- `BuildCtx` の `cache` / `syntax_set` / `syntect_theme` は `Highlighter` 1 つに畳んだ
- `LineMeta` の `entry` / `block` は残したが、`Pos` からは落とした (markdown の
  キャッシュキーにしか使っていなかった)
- session id の照合は `TerminalPanel::install_transcript` の 1 箇所。`Reflow::install` は
  照合済みの前提で受け取る
